## ⚠ Status caveat

The 3DS Virtual Console, Nintendo Switch Online's Game Boy app (2023), and
publisher collections all count as releases on another platform. Nintendo has been
thorough with this library, so **the `Ported` share is high**.

## Summary

| | Count |
|---|---|
| **Debut games** | **34** |
| of which still `Stranded` | 11 |
| of which since `Ported` | 22 |
| **Contested** | 2 |

**Why the Game Boy strands games.** Three causes, one of them unique to this
platform:

1. **Cartridge hardware.** The Game Boy is the only system here whose *games*
 contained hardware. `Kirby Tilt 'n' Tumble` has an accelerometer in the cart.
 `Pokémon Pinball` has a rumble motor and a battery. The `Game Boy Camera` is a
 camera. None of these can be reproduced by a software re-release, which is why
 Nintendo has quietly skipped them for 25 years.
2. **Dead licences**, as on NES and SNES.
3. **Link Cable dependency.** Trading and battling were the point of several
 titles, and the physical cable has no modern equivalent.

Note the platform's most famous game is **not catalogued here**: `Tetris` debuted
on a Soviet Electronika 60 in 1984, so the Game Boy pack-in is a port.

## Appendix: the tails

- **Licensed tie-ins (~300 titles).** Film, cartoon and TV licences from LJN,
 THQ, Ocean, Acclaim and Absolute. Overwhelmingly stranded.
- **Japan-only releases (~250 titles).** Mahjong, pachinko, anime tie-ins and a
 deep RPG tail.
- **Hardware cartridges.** Beyond the entries above, several Japanese carts
 contained sensors, IR ports or rumble. These are the platform's most
 permanently stranded software.

## Coverage gaps

- Licensed and Japan-only tails characterised, not enumerated.
- NSO's Game Boy library rotates and grows; `Ported` is a floor.
- Game Boy Color exclusives are catalogued separately in [game-boy-color.md](game-boy-color.md).
